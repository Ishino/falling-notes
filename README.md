# Falling Notes – piano practice

A single-page app that shows sheet music as falling notes over a piano keyboard (Synthesia / "Rush E" style), at the right tempo, with speed control, wait mode, hand selection, looping and USB MIDI keyboard input.

Open: https://ishino.github.io/falling-notes/

Loads MusicXML (.musicxml/.mxl/.xml) and MIDI (.mid) files, or notes typed bar by bar in the editor. (Reading photos of sheet music only works in the claude.ai version.)
